# Crimpify

Session generator for boulderers. Generate a training session that fits your
time and equipment, run it with timers, log how it felt with one tap, and pass
it on as a link. Free, no account, works offline.

Live at [crimpify.com](https://crimpify.com).

Vanilla JavaScript PWA: `index.html`, `app.js` and `style.css`, no build step
and no dependencies. All user data stays in localStorage on the device, and a
shared session travels fully encoded in the URL.
